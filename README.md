# Акваспектр

Адаптивный сайт компании по проектированию, строительству и обслуживанию бассейнов, аквапарков, искусственных волн и фонтанов. Сделан по предоставленному макету на HTML, CSS и JavaScript без зависимостей.

## Запуск

Требуется Node.js 20 или новее. Устанавливать пакеты не нужно.

```sh
npm run dev
```

Откройте http://localhost:5173. Другой порт: `npm run dev -- --port 3000`.

```sh
npm run check
npm run build
```

Папка `dist/` — готовый статический сайт для размещения на хостинге в корне домена. Сервер `scripts/server.mjs` предназначен для разработки, а не для публичного размещения.

## Реализовано

- Адаптивная вёрстка, мобильное меню, якорная навигация.
- Фильтрация каталога и подробности проектов в модальных окнах.
- Раздел искусственных волн.
- Форма подготовки описания проекта с проверкой полей, скачиванием TXT и ссылкой для звонка.
- Клавиатурная навигация, закрытие окон по Escape, reduced-motion.
- Локальные изображения и шрифты: внешних запросов при просмотре нет.

## Перед публикацией

1. Проверить номер `+7 (928) 987 97 07`, перенесённый с макета: он указан в `index.html` и `src/main.js`.
2. Заменить демонстрационные изображения реальными снимками объектов. Названия и размеры трёх проектов перенесены с макета; их следует подтвердить у заказчика. Пример искусственной волны — иллюстрация предлагаемого решения.
3. Заменить приближённый SVG-логотип оригинальным фирменным файлом.
4. Подключить согласованный канал отправки заявок (CRM, почта или серверный API). Сейчас форма готовит файл локально, не отправляет данные и прямо сообщает об этом. Цены не выдумываются: стоимость определяется после консультации.

## Деплой в Timeweb App Platform

Для режима **HTML/CSS/JS** платформа использует готовые файлы и не выполняет сборку.

1. Выполнить `npm run check` и `npm run build` локально.
2. Загрузить проект вместе с папкой `dist/` в выбранный Git-репозиторий. Папка `dist/` намеренно не исключена в `.gitignore`.
3. Выбрать репозиторий сайта и нужную ветку в Timeweb App Platform.
4. Фреймворк: **HTML/CSS/JS**. Директория проекта: **dist**. Команды сборки и запуска для этого режима не нужны.
5. Проверить сайт по техническому домену приложения.
6. В настройках приложения привязать существующий домен. На стороне провайдера DNS заменить записи сайта, указывающие на Тильду, значениями из Timeweb. Для `www` проверить отдельную привязку и записи. Почтовые записи MX и TXT сохраняются.
7. Дождаться обновления DNS и выпуска SSL-сертификата, проверить HTTPS.

При каждом изменении сайта повторять сборку и включать обновлённую папку `dist/` в коммит.

Документация: https://timeweb.cloud/docs/apps/deploying-frontend-apps/static-website
